SETUP
Python 3.11, 3.12, 3.13 or 3.14 (64-bit). In the unzipped folder: python -m venv .venv, activate it, then pip install -e .
Python 3.10 and Intel Macs cannot install the required onnxruntime.
No training framework is included: use PyTorch, TensorFlow, JAX… anything that exports ONNX.
WHAT IS MCTS?
Monte-Carlo Tree Search: the search that picks the moves. It simulates possible continuations and asks your model two things about
each position – which moves look promising, and how good the position is.

One file, model.onnx: ONNX opset 13–18, weights inside the file, at most 5 MiB.
Input (one): float32 (batch, 16, 8, 8) – the board seen from the side to move, as 16 planes (docs/observation.md).
Output 1, policy: float32 (batch, 4096) – a raw score per action, action = from_tile × 64 + to_tile. Illegal actions are ignored.
Output 2, value: float32 (batch) between -1 and 1 – how good the position is for the side to move.
The batch dimension must be dynamic, with the same name on the input and both outputs.
LIMITS
Standard layers only: convolutions, linear layers, activations, normalization, pooling and reshapes with fixed shapes. No loops, no
if, no data-dependent shapes.
Checking a model must take under 3 seconds, a Level 3 match under 20 seconds. Small networks are far below that.
One upload every 30 seconds per team.
WHEN A MODEL IS REJECTED
The page shows the reason. tools/validate_submission.py gives the same message locally.
If you get the "Model dry run exceeds the 3-second limit" error, please try again.
The full specification, with the complete list of allowed layers and the common export fixes, is in docs/submission.md.
