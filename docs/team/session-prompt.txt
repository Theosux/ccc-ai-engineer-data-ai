6. THE SOLVING WORKFLOW (per level; skills ccc-ai-solve + ccc-ai-patterns)
------------------------------------------------------------------------------------------------------
1. `python arena/ccc.py fetch N` prints the statement, input sizes, extra files, example input + expected output.
   Extract: exact OUTPUT FORMAT (copy the example byte for byte: header row, separators, decimals, id order),
   METRIC + THRESHOLD PER FILE (only in the PDF text; can differ per file), story sentences that are RULES,
   which rows are train vs test. Image-only pages → `fetch N --png` and read the PNGs.
2. One exploration script: TRAP HUNT (non-numeric values in numeric columns like "seventeen", unit clusters
   like °F mixed into °C or Kelvin, NaN/"missing"/"?", outliers outside ranges given in the PDF, wrong-length
   rows, duplicates; earlier levels' data is re-shipped with the same bugs) + a CV table with the PDF metric
   (`lib.ml.best_model`). For time series: rolling-origin validation, never random CV. For exact/100%/password
   levels: look for an exact relation to older data (reversal, shift, duplicate, reshape to an image).
3. Write `arena/runs/<run>/levelN/solve.py` with the Write tool (stdin → stdout, diagnostics on stderr) and a
   `check(data, out)` that validates the format, so `go` accepts predictions that differ from the example.
4. `python arena/ccc.py go N` (long tool timeout; heavy training `--timeout 900`). It runs, checks, submits
   sequentially, and **the verdict shows the achieved score, on CORRECT and on WRONG** (e.g.
   "RMSE = 2.5604 (limit 6.00)"). On PASS it prints the next level.
5. Not passing → ladder: re-read the story for a missed rule/trap → check the noise floor (all models equal =
   hidden formula or feature needed) → better features from story/structure → model blend/seeds → class
   weights/threshold tuning → after 15 min, second opinion from the other person.

  deep nets were needed only for images → keep pretrained CNN embeddings + LogReg as the image fallback.

8. HARD-WON RULES (each one cost real minutes in training)
------------------------------------------------------------------------------------------------------
- Traps before models, every level. Read every story page: the rules are in the prose.
- Linear model first on regression (Birds L2: linear 2.58 RMSE beat LightGBM 2.92).
- Files with no labels: train on labelled rows pooled from all files of the level.
- Grade per group (flock/day): aggregate to one feature row per group.
- Forecasting: validate at several cutoffs with the task's horizon; scores varied 0.42–0.70 by cutoff.
- pandas 3 reads text columns as dtype "str", not "object" (use `pd.api.types.is_numeric_dtype`).
- Submit only from ONE laptop (the server loses concurrent submits). Never pipe `go` into tail/grep and then
  chain a submit. Write/Edit solvers, never heredoc/`python -c` patches. No side work while a level is unsolved.
- Submit when CV clears the threshold with margin; one calibration submit is fine when validation is doubtful
  (a wrong-submit penalty in 2026 is unconfirmed — don't spam).
- Never commit inputs > 50 MB (add them to .gitignore; anyone can re-fetch).
